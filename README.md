# CobblemonGen2

CobblemonGen2 brings Pokémon #001--493 to Gen1Recomp.

## Files Needed

### 1. Cobblemon 1.8.1

Download **Cobblemon 1.8.1 for Minecraft 1.21.1 / Fabric** - Download as .zip (around 147mb windows view or 150,923mb properties view)

### 2. CCC 2.1

Download **CCC 2.1 for Minecraft 1.21.1 / Data Pack**:

Choose **2.1 Release (17.87Mib)** - not Download as .zip (around 17.9mb windows view or 18,304mb properties view)
## Build

Open the CobblemonGen2 Builder.

Select: - Cobblemon 1.8.1 - CCC 2.1

Press **BUILD**.

The builder will create:

-   `Cobblemon493Pack.zip`
-   `CobblemonGen2.zip`

## Install

Place `Cobblemon493Pack.zip` and `CobblemonGen2.zip` in your Gen1Recomp
mods folder.

Enable **CobblemonGen2** from the mod menu.
